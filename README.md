# StarkFlow — Multiplayer game SDK for selfhost gaming servers

Игровой SDK для мультиплеера на self-hosted серверах.

## Компоненты

- `client/` — клиентская часть (игровой рантайм)
- `server/` — серверная часть (self-host)
- `sdk/` — публичные API / обёртки для игровых движков
- `docs/` — документация

> Структура каталогов будет наполняться по мере развития проекта.

## Сборка и запуск

Инструкции по сборке и запуску появятся вместе с первым кодом.

```bash
git clone https://github.com/EwenLoy/starkflow.git
cd starkflow
```
