# Документация StarkFlow

Подробные доки к серверу и плагину Construct 3. Краткий обзор проекта, быстрый старт и бейджи — в
[корневом README](../README.md).

## Что где лежит

| Документ | О чём | Когда открывать |
|---|---|---|
| [PLUGIN.md](PLUGIN.md) | установка аддона, первый пример, правила id | первый запуск в C3 |
| [GAME-GUIDE.md](GAME-GUIDE.md) | пошагово: лобби, комнаты, стейт, события, ошибки, синк объектов | делаешь игру |
| [ACE.md](ACE.md) | все действия, условия и выражения с параметрами, коды ошибок, лимиты | справочник под рукой |
| [DEPLOY.md](DEPLOY.md) | ПК с туннелем, VPS, свой домен и https, боты-хостинги, WebRTC, переменные окружения | поднимаешь сервер |
| [CLUSTER.md](CLUSTER.md) | несколько нод, регионы, directory, админ-панель | одна нода уже не тянет |
| [DEVELOPMENT.md](DEVELOPMENT.md) | локальный запуск, встроенный тестовый клиент, тесты, CI | правишь код |
| [PROTOCOL.md](PROTOCOL.md) | сообщения по WebSocket, батчинг, стейт, `sync`, `rtc.*` | пишешь свой клиент |

## С чего начать

- **Делаю игру.** [PLUGIN.md](PLUGIN.md) → [GAME-GUIDE.md](GAME-GUIDE.md) → [ACE.md](ACE.md) по мере надобности.
- **Поднимаю сервер для друзей.** Быстрый старт в [README](../README.md#quick-start) → [DEPLOY.md](DEPLOY.md) →
  [CLUSTER.md](CLUSTER.md), если нужны регионы.
- **Пишу свой клиент или правлю сервер.** [PROTOCOL.md](PROTOCOL.md) → [DEVELOPMENT.md](DEVELOPMENT.md) →
  код в `server/internal/proto` и `server/internal/server`.
