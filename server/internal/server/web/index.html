    HP босса— / —

    HP общий: удар любого игрока меняет его у всех сразу. Ключ boss_hp создан в режиме add с границами 0…1000 и maxDelta 50, поэтому set запрещён (402), дельта больше 50 отбивается (403), а значение зажимается в границах. Значения пишет сервер, клиенты не могут их подделать.

    кадров/с

    Веди мышь по полю — своя позиция уходит в стейт игрока (player.set), поэтому перезаписать чужой курсор нельзя, а лимит ключей комнаты не расходуется. Клик по полю отправляет событие: у остальных в этом месте вспыхивает кружок. Рамка вокруг ника — это ты.
